# データと引っ越し

## データの書き出しと読み込み

「設定」の「アカウントのデータ」(`/settings/account-data`)で、データをファイルに書き出せます。書き出したファイルは、できあがるとドライブに入ります。

| データ | 形式 | 読み込み |
| --- | --- | --- |
| 全てのノート | JSON | できない |
| お気に入りにしたノート | JSON | できない |
| クリップ | JSON | できない |
| フォロー | CSV | できる |
| リスト | CSV | できる |
| ミュート | CSV | できる |
| ブロック | CSV | できる |
| アンテナ | JSON | できる |

ノートは書き出せても、別のサーバーに読み込んで投稿し直すことはできません。

読み込みができるかは、サーバーの管理者がロールで決めます。初期設定では、5 種類とも読み込めません。

書き出しには回数の制限があります。ノート・お気に入り・クリップは 1 日 1 回、フォロー・ミュート・ブロック・アンテナは 1 時間 1 回です。

設定の画面そのもの(テーマやタイムラインの設定など)は、これとは別に、設定のプロファイルのメニューから書き出しと読み込みができます。

## 別のアカウントへ引っ越す

アカウントの移行を使うと、フォロワーを新しいアカウントに移せます。ノートやファイルは移りません。移行は取り消せず、移行したあとの古いアカウントではノートを書けなくなります。

1. 古いアカウントで、フォロー・リスト・ミュート・ブロックを書き出しておく
2. 新しいアカウントで「設定」の「その他」(`/settings/other`)から「別のアカウントからこのアカウントに移行」を開き、古いアカウントを `@ユーザー名@サーバー` の形で入れて保存する
3. 古いアカウントで、同じ「その他」から「このアカウントを新しいアカウントへ移行」を開き、新しいアカウントを入れて「移行する」を押す
4. 新しいアカウントで、書き出しておいたフォローなどを読み込む(新しいサーバーで読み込みが許されている必要がある)

古いアカウントからのフォローは、移行のおよそ 24 時間後に外れます。

## アカウントを削除する

「設定」の「その他」の「アカウントを閉鎖する」から「アカウント削除をリクエスト」を押し、パスワード(設定していれば 2 段階認証も)を入れます。削除は少しずつ進むので、終わるまでに時間がかかります。メールアドレスを確認済みなら、終わったときにメールが届きます。
