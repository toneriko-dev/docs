# 使い方

Toneriko のサーバーにアカウントを持つ人向けの説明です。画面の名前は、日本語の表示のものを使っています。

このページに書く上限や初期値は、Toneriko の初期設定のものです。サーバーの管理者は、ロールやサーバーの設定でこれを変えられるので、使っているサーバーでは違うことがあります。

## 読む順番

- [タイムライン](./timelines): ホーム・ローカル・ソーシャル・グローバルの違いと、リスト・アンテナ・チャンネル
- [ノートを書く](./notes): 公開範囲、注釈(CW)、アンケート、ファイルの添付、予約投稿と下書き
- [リアクション](./reactions): 絵文字の付け方と、受け付けるリアクションの選び方
- [ドライブ](./drive): ファイルの置き場所と容量、センシティブの指定
- [MFM](./mfm): ノートの文字を飾る書き方
- [アカウントの安全](./security): 2 段階認証、パスキー、ログインの方法
- [データと引っ越し](./moving): データの書き出しと読み込み、別のアカウントへの移行、アカウントの削除
