# MFM

MFM は、ノートの文字を飾る書き方です。投稿の画面の「装飾を追加」から選んで入れることもできます。

Markdown に似ていますが、別の書き方です。`# 見出し` や `- 箇条書き` は、飾られずにそのまま表示されます。

## 文字の飾り

| 書き方 | 表示 |
| --- | --- |
| `**太字**`、`<b>太字</b>` | 太字 |
| `<i>斜体</i>` | 斜体 |
| `~~打ち消し~~`、`<s>打ち消し</s>` | 打ち消し線 |
| `<small>小さく</small>` | 小さく薄い文字 |
| `<center>中央</center>` | 中央に寄せる(行の頭に書く) |
| `> 引用` | 引用 |
| `` `コード` `` | 1 行のコード |
| ` ``` ` で囲む | コードのかたまり。` ```js ` のように言語の名前を書くと色が付く |
| `<plain>そのまま</plain>` | 中身を飾らずにそのまま表示する |

`*斜体*` と `__太字__` の書き方もありますが、日本語には効きません。日本語を飾るときは `<i>` と `**` を使ってください。`***文字***` は太字の斜体ではなく、下の `tada` の飾りになります。

## リンクとメンション

| 書き方 | 表示 |
| --- | --- |
| `@user`、`@user@example.com` | メンション |
| `#タグ` | ハッシュタグ |
| `https://…` | リンク |
| `[表示する文字](https://…)` | 文字に付けたリンク |
| `?[表示する文字](https://…)` | URL のプレビューを出さないリンク |
| `:emoji_name:` | カスタム絵文字 |
| `語 検索` | 検索の欄。行全体に書く。`検索` の代わりに `[検索]`、`Search` も使える |

検索の欄で使う検索エンジンは、設定で Google・DuckDuckGo・Bing・Brave Search から選べます(初期値は Google)。

## 動きと見た目の飾り

`$[名前 文字]` の形で書き、名前のあとには空白を入れます。`$[名前.引数=値 文字]` のように、引数を付けられるものもあります。

| 名前 | 効果 |
| --- | --- |
| `tada`、`jelly`、`twitch`、`shake`、`spin`、`jump`、`bounce` | 文字が動く。`speed=2s` で速さ、`delay=1s` で始まるまでの時間を変えられる |
| `rainbow` | 虹色。動きを止める設定でも色は付く |
| `sparkle` | きらめき |
| `flip` | 左右を反転する。`.v` で上下 |
| `x2`、`x3`、`x4` | 大きくする(文字の大きさで 200%・400%・600%) |
| `scale` | `.x=2,y=0.5` のように縦横の倍率を変える。5 倍まで |
| `position` | `.x=1,y=-1` のように位置をずらす(単位は文字の大きさ) |
| `rotate` | `.deg=45` のように回す。初期値は 90 度 |
| `fg`、`bg` | 文字の色、背景の色。`.color=f80` のように `#` なしの 16 進で書く |
| `border` | 枠を付ける。`width`、`style`、`color`、`radius` |
| `font` | `.serif`、`.monospace`、`.cursive`、`.fantasy` |
| `blur` | ぼかす。カーソルを載せると見える |
| `ruby` | `$[ruby 漢字 かんじ]` のようにふりがなを付ける |
| `unixtime` | UNIX 時間(秒)を日時で表示する |

動く飾りは、「設定」で「動きのあるMFMを有効にする」を切ると止まります。初期値は、端末の「視差効果を減らす」の設定に合わせて決まります。

```
$[tada よろしくおねがいします]
$[fg.color=26739f 色の付いた文字]
$[ruby 梣 とねりこ]
```
