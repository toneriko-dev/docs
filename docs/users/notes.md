# ノートを書く

投稿の画面で本文を書いて「ノート」を押すと投稿されます。本文は 3,000 文字までです。画面の文字数は JavaScript の数え方なので、絵文字の 😀 は 2 文字と数えます。

## 公開範囲

ノートをだれに見せるかを、4 つから選びます。初期値は「パブリック」です。

| 名前 | 見える人 |
| --- | --- |
| パブリック | だれでも。ローカルとグローバルのタイムラインにも流れる |
| ホーム | だれでも。ただし、ローカルとグローバルのタイムラインには流れない |
| フォロワー | 自分とフォロワー。返信先のユーザーと、メンションしたユーザーにも見える |
| 指名 | 指定したユーザーと自分 |

「ホーム」は非公開ではありません。プロフィールやノートの URL からは、だれでも読めます。

「フォロワー」のノートも、返信先とメンションしたユーザーには見えます。フォロワー以外には決して読まれない、という意味ではありません。

ほかに「連合なし」を付けると、ほかのサーバーへノートを送りません。返信・引用・リノートの元が連合なしなら、そのノートも連合なしになります。

返信は、返信先より広い公開範囲にはできません。

## 注釈(CW)

「内容を隠す」を使うと、注釈を付けて本文を畳んで表示できます。注釈は 1〜100 文字です。読む人は、注釈を見てから本文を開けます。

## アンケート

選択肢は 2〜10 個、それぞれ 1〜50 文字で、同じ選択肢は 2 つ置けません。複数回答を許すか、期限(無期限・日時を指定・投稿からの時間を指定)を選べます。

## ファイルの添付

ファイルは、選ぶ・貼り付ける・ドラッグして置く、のどれかで添付できます。1 つのノートに 16 個まで付けられ、本文が無くても投稿できます。投稿の前に、名前を変えたり、画像を切り抜いたりできます。

添付したファイルは[ドライブ](./drive)に保存されます。

## 予約投稿と下書き

その他のメニューの「投稿を予約…」で日時を決めると、その時刻に投稿されます。同時に予約できるのは 1 件で、予約した日時はあとから「予約投稿一覧」で変えられます。

「下書きへ保存」で、サーバーに下書きを 10 件まで残せます(予約投稿も、この 10 件に含む)。下書きと予約投稿の一覧は、投稿の画面のアカウントのメニューから開きます。

書きかけの本文は、これとは別に端末にも自動で残ります。次に投稿の画面を開いたときに戻すかは、設定で「常に復元する」「復元前に確認する」「復元しない」から選べます。

## 返信・引用・リノート

- 返信: ノートに答える投稿
- 引用: 元のノートを付けた新しい投稿
- リノート: 元のノートを自分のタイムラインに流し直す

ほかの人の「フォロワー」と「指名」のノートは、リノートできません。「ホーム」のノートをリノートすると、リノートも「ホーム」になります。
