# アカウントの安全

「設定」の「セキュリティ」(`/settings/security`)から、2 段階認証とパスキーを設定できます。

## 認証アプリ(2 段階認証)

ログインのときに、パスワードに加えて、スマートフォンの認証アプリの 6 桁のコードを求めるようにします。

1. 「二要素認証」の「認証アプリの設定を開始」を押し、パスワードを入れる
2. 表示された QR コードを認証アプリで読み取る(アプリを開くボタンや、URI を入れる方法もある)
3. アプリに出た 6 桁の確認コードを入れる
4. バックアップコードが表示されるので、保存する(「ダウンロード」でファイルにもできる)

バックアップコードは 5 個で、それぞれ 1 回だけ使えます。スマートフォンを無くしたときは、ログインの画面で「バックアップコードを使う」に切り替えて入れます。認証アプリを設定し直すと、前のバックアップコードは使えなくなります。

## セキュリティキーとパスキー

認証アプリを設定したあと、セキュリティキーやパスキーを登録できます。「セキュリティキー・パスキーを登録する」を押し、キーの名前(1〜30 文字)を入れて、ブラウザや端末の案内に従います。

登録しただけでは、パスワードなしではログインできません。同じ画面の「パスワードレスログイン」を有効にすると、ログインの画面の「パスキーでログイン」から、パスワードを入れずにログインできます。

セキュリティキーを登録していると、認証アプリだけを外すことはできません。その場合は「認証アプリを再設定」になります。

## ログインの流れ

| 設定 | ログインの画面 |
| --- | --- |
| 何も設定していない | ユーザー名、パスワードの順に入れる。サーバーによっては CAPTCHA もある |
| 認証アプリ | パスワードのあとに確認コードを入れる |
| セキュリティキー・パスキー | パスワードのあとにキーで認証する。確認コードに切り替えることもできる |
| パスワードレスログイン | 最初の画面で「パスキーでログイン」を押す |
