# リアクション

ノートのリアクションのボタンを押すと絵文字の一覧が開き、選んだ絵文字をノートに付けられます。Unicode の絵文字のほか、サーバーのカスタム絵文字も使えます。

1 つのノートに付けられるリアクションは、1 人 1 種類です。別の絵文字を選ぶと付け替わり、もう一度押すと取り消せます。

## 受け付けるリアクションを選ぶ

ノートを書くときに、その他のメニューの「リアクションの受け入れ」で、受け付けるリアクションを 5 つから選べます。Web の初期値は「非センシティブのみ」です。

| 名前 | 受け付けるもの |
| --- | --- |
| 全て | すべて |
| 全て (リモートはいいねのみ) | このサーバーの人からはすべて、ほかのサーバーの人からはいいねだけ |
| 非センシティブのみ | センシティブに指定されたカスタム絵文字を除くすべて |
| 非センシティブのみ (リモートはいいねのみ) | このサーバーの人からは非センシティブのみ、ほかのサーバーの人からはいいねだけ |
| いいねのみ | ハートのいいねだけ |

「いいねのみ」のノートでは、ボタンを押すと絵文字の一覧を開かずにハートが付きます。受け付けない絵文字や、使う権限の無いカスタム絵文字を付けると、ハートに置き換わります。

リノートそのものにはリアクションを付けられず、元のノートに付きます。
